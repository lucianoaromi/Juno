# JUNO v0.9 — Simplificación definitiva de Programas de inicio

Fecha: 2026-10-22. Rama: feature/juno-ui-0.9.

La sección contiene únicamente PROGRAMAS DE INICIO, «Administrá qué aplicaciones se ejecutan automáticamente al iniciar Windows.» y el botón secundario Configurar en Windows. Se retiraron tabla, nombres, estados, contador, controles individuales, actualización, restauración y diagnósticos de esta vista. Tampoco enumera aplicaciones al abrirse o navegar.

El botón conserva el lanzador existente de la URI oficial ms-settings:startupapps mediante el shell de Windows, sin elevación ni espera al cierre. Se ejecutó el lanzador real de producción y se comprobó visualmente la página Aplicaciones → Inicio en Windows 11. Se cerró sin cambiar opciones. La conexión del botón con el lanzador y los errores se verifican con simulaciones; no se certificó una pulsación de JUNO en una sesión interactiva completa. Windows 10 usa la misma URI oficial, pero queda pendiente su comprobación física.
Referencia: [Microsoft: inicio de Configuración de Windows](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings).

La altura se adapta al contenido, sin reservar espacio para una lista. Las pruebas comprueban límites y ausencia de superposiciones a 1180×790, 940×650 y 700×500. Se conservan el tema y los botones secundarios existentes. Durante una operación pendiente se bloquea el acceso y se habilita al terminar.

## Recuperación histórica

El motor, el almacén de respaldos y el servicio PowerShell de inicio no se modificaron para esta simplificación. La recuperación está en la tarjeta existente de Restauración → Programas de inicio → Comprobar respaldos. Restaurar cambios aparece cuando corresponde y conserva la confirmación y las validaciones existentes. La prueba integrada usa proveedores y respaldos temporales simulados para comprobar la recuperación de los originales. No se realizaron restauraciones reales.

# JUNO v0.9 — Controles de Transparencia

La tarjeta destaca Desactivar cuando la instantánea verificada indica Enabled, y Activar cuando indica Disabled. El resaltado exige CanChange. Los errores y estados desconocidos no destacan acciones incompatibles. La restauración conserva la elegibilidad del adaptador.

Durante una operación se conserva la instantánea previa, con controles deshabilitados, hasta recibir el resultado. Los secundarios tienen fondo y borde discretos; no cambian tipografía, dimensiones ni distribución. Solo se modificaron ui/JunoShell.cs y tests/Transparency.Tests.ps1 en esta corrección visual.

Validación previa a Etapa 3B, 18/10/2026: 467/467 pruebas en Windows PowerShell 5.1 x64 y 467/467 en x86; 28 scripts sin errores de sintaxis, C# compilado en ambos hosts y git diff --check correcto. Las pruebas de Transparencia usan proveedores simulados. No se aplicaron cambios reales de Windows.

Los informes 3A y 3A.1 conservan el estado Git histórico de sus respectivas entregas. Al comenzar 3B se guardan esos cambios y esta corrección en el commit local `feat: integrate transparency with secure recovery`. No se incluye Nueva carpeta/ ni se realiza push o fusión.

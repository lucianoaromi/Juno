# JUNO v0.9 — Accesos de configuración de energía y transparencia

Fecha: 2026-10-22. Rama: feature/juno-ui-0.9.

## Cambio

Se sustituyeron únicamente los botones Ver detalles de Plan de energía y Transparencia por Configurar en Windows. Se utiliza el mismo PreviewButton secundario, ToolButton y ToolActions de Efectos visuales, sin modificar la estructura, dimensiones ni distribución de las tarjetas.

Energía reutiliza el acceso clásico control.exe /name Microsoft.PowerOptions. El ejecutable se resuelve por ruta absoluta en la carpeta del sistema; en un proceso x86 sobre Windows x64 se utiliza Sysnative. Transparencia abre ms-settings:colors mediante el shell oficial. No hay solicitudes de elevación, confirmaciones de JUNO ni espera al cierre de las ventanas. Las excepciones muestran un mensaje breve en la barra existente.

Se conservan las acciones originales, estados, respaldos, permisos y restauración. Los diagnósticos internos siguen disponibles en el código; ya no se exponen mediante esos dos botones. No se modificaron los motores ni los diagnósticos de persistencia de Efectos visuales.

## Verificaciones reales y límites

Se ejecutaron los lanzadores de producción. En Windows 11 se comprobó visualmente Personalización → Colores con su opción Efectos de transparencia. También se verificó la creación de la ventana oficial Opciones de energía al ejecutar el lanzador fuera del aislamiento de pruebas. El código no solicita runas ni elevación administrativa; para esta comprobación fue necesario salir del aislamiento de pruebas. La captura del contenido de ese panel quedó pendiente porque venció el permiso de Computer Use para esa ventana.

La primera apertura de Colores reveló que ShellExecute puede devolver un proceso nulo aunque haya abierto correctamente la ventana; se eliminó la interpretación de ese caso como error y se repitió la apertura sin excepciones. Los errores reales de Process.Start continúan mostrando el aviso breve.

Se inspeccionó el renderizado WinForms de JUNO con proveedores ficticios, incluidos los botones de restauración. Las pulsaciones de botones se verificaron en las pruebas simuladas; las ventanas oficiales se comprobaron ejecutando los lanzadores de producción por separado. No se modificaron opciones de Windows.

En Windows 10 queda pendiente comprobar físicamente ambos accesos y su presentación. No se certifica una sesión interactiva completa de JUNO en ese sistema.
